# Source playbooks

The why skill spawns one investigator per evidence source, each reading a single playbook below. Orbi has two sources, and both are always available.

| Source | Playbook | What it covers |
|---|---|---|
| Source control history | [`code-archaeology.md`](./sources/code-archaeology.md) | git history, commit messages, inline comments, tests |
| Orbi records | [`orbi-records.md`](./sources/orbi-records.md) | `docs/adr/`, `docs/vision.md`, `docs/roadmap.md`, `docs/research/`, `journal/` (local only), annotated phase tags, `CONTEXT.md` |
